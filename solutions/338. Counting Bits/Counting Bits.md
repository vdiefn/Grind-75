## 題目說明
給定一個整數 n，請回傳一個長度為 n + 1 的陣列 ans。對於每個 i ($0 \le i \le n$)，ans[i] 必須是數字 i 在二進位表示法中 1 的個數。

## 解題思路
|十進位 (i)|二進位表示|1 的數量|十進位 (i/2)|二進位表示|1 的數量|
|:---:|:---:|:---:|:---:|:---:|:---:|
|2|10|1|⬅️|1|0|1|1|
|3|11|2|⬅️|2|10|1|
|4|100|1|⬅️|2|010|1|
|5|101|2|⬅️|4|100|1
|6|110|2|⬅️|3|011|2|
#### 從上表可以觀察到
- 當n為偶數時，1的數量會看n/2的數量一樣。例如：數字4和數字2在2進制時的數字1的數量是一樣的。
- 當n為奇數的時候，1的數量會是n-1這個數字的數量+1
#### 因此只要寫一個for循環，將相應的數字放到陣列中即為答案
### 注意
1. 題目是從$n$開始，但是回傳的陣列長度是$n+1$，因此陣列的第一個數字會是從$0$開始
2. for迴圈的i會從$1$開始
3. 陣列可以初始化為`let array = []`或者寫成`let array = new Array(n+1).fill(0)`
